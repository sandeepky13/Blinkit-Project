# 📊 Blinkit Sales Dashboard | Power BI Project

## 📌 Project Overview

This project presents a **Blinkit Sales Analysis Dashboard** built using **Power BI** to analyze sales performance, customer behavior, outlet performance, and product insights.

The dashboard provides interactive visualizations to help understand business trends and support data-driven decision-making.

---

## 🚀 Features

✔ Interactive Power BI Dashboard  
✔ Sales Performance Analysis  
✔ Outlet Performance Tracking  
✔ Product Category Analysis  
✔ Customer Rating Insights  
✔ Filter & Slicer Functionality

---

The dashboard analyzes key business metrics such as:

- **Average Sales**
- **Average Customer Rating**
- **Number of Items Sold**
- **Outlet Performance**
- **Category-wise Sales Analysis**

## 📊 Dashboard Insights

### 1. Sales Performance Analysis
Analyze total revenue and sales trends.

### 2. Outlet Analysis
Compare outlet performance by:

- Outlet Size
- Outlet Location
- Outlet Type

### 3. Product Category Analysis
Identify best-performing product categories.

### 4. Customer Rating Analysis
Understand customer satisfaction trends.

### 5. Fat Content Analysis
Analyze sales distribution by fat content category.
